# Nishant Dave {Blog}

Personal site rebuilt with [Astro](https://astro.build) and deployed to [GitHub Pages](https://nishantdave.github.io).

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Push to `main` — a GitHub Actions workflow builds the site and deploys it to GitHub Pages automatically.
